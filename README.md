# Python Menu-Driven Calculator

A simple command-line calculator built in Python. Apart from basic arithmetic, it also handles exponents, square roots, and keeps track of calculation history during the session.

### Features
- Basic operations: Addition, Subtraction, Multiplication, Division
- Extra math functions: Power (x^y) and Square Root
- Session History: Saves all calculations in a list so you can view or clear past results
- Error handling: Prevents crashes from division by zero, negative square roots, or text inputs
